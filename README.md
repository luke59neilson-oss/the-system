# The System

Software for running a LitRPG tabletop campaign in the style of Zogarth's
*The Primal Hunter*. The GM runs a double-click app on their laptop; players
on the same wifi open the join address in a browser and pick their character.

Status: in development. See `docs/PROGRESS.md`.
